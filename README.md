# VisionCut Agency Website

A production-ready, SEO-focused full-stack website for VisionCut, a creative digital marketing agency in Karnataka, India.

## Tech Stack
- Next.js (App Router) + React
- Tailwind CSS + Framer Motion
- Node.js API routes
- MongoDB with Mongoose

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env.local` file:

```
MONGODB_URI=mongodb+srv://...
JWT_SECRET=your-secret
```

## Features
- Animated UI with page transitions and scroll reveal
- Dark + light mode
- MongoDB-backed blog, services, portfolio, and contact storage
- SEO schema (LocalBusiness, MarketingAgency, BlogPosting)
